DESIGN DIRECTION:

Visual style:

- Minimal but visually rich

- Premium corporate aesthetic

- Strong typography

- Large editorial-style headings

- Spacious layouts

- Sophisticated neutral background

- Black/charcoal + white + one strong brand accent color

- Subtle gradients

- Rounded cards where appropriate

- High-quality business/office/entrepreneur imagery

- Smooth scroll animations

- Subtle hover interactions

- Modern micro-interactions

- Elegant transitions

- Lots of whitespace

- Strong visual hierarchy

- Mobile-first responsive design

- Avoid generic template/AI-generated appearance
